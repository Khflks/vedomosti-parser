# Парсер новостей Ведомостей
Этот скрипт собирает новости с сайта «Ведомости» по заданным ключевым словам.

Особенности:
* Использованние API не подходит из-за платной подписки (ошибка `not_subscriber`).
* В качестве источника данных используются открытые RSS-ленты (`feedparser`).
* Результаты сохраняются в базу данных SQLite (`db.sqlite3`).

Как запустить:
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите скрипт: `python crawler_vedomosti.py`
